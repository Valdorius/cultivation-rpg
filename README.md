# 🌟 Путь к Бессмертию (修仙录 — Xianxia Text RPG)

Атмосферная мобильная текстовая RPG в жанре классического китайского культиваторского фэнтези (Сянься / Сюаньхуань).

---

## ⚡ Особенности игры

- **Истинный путь культивации:** Ступени от Закалки Тела и Конденсации Ци до Возведения Основания, Золотого Ядра и Зарождающейся Души.
- **Небесная Скорбь (Heavenly Tribulation):** Удары громовых молний и испытания Демонов Сердца при прорыве узких мест.
- **Жесткий таймер Долголетия:** Годы уходят во время уединенной медитации. Не успели прорваться до истечения срока — душа растворится в круге Сансары.
- **Духовные корни:** От мусорного корня 5 стихий до Небесного Корня Чистого Пламени и Мутировавшей Молнии.
- **Бронзовый Алхимический Котел:** Сбор редких трав и варка пилюль прорыва с риском взрыва котла.
- **Случайные встречи:** Высокомерные молодые господа древних кланов, запечатанные пещеры древних бессмертных и поручения сект.
- **Священные звуки Дао:** Процедурный синтез звуков через Web Audio API (гонг прорыва, раскаты небесной молнии, гул медитации) без внешних тяжелых файлов.
- **PWA & Офлайн:** Игра поддерживает установку на рабочий стол Android в один клик и работает без интернета.

## 📱 Запуск на Android

### 1. Локальный запуск на устройстве

В терминале Antigravity перейдите в папку проекта и запустите локальный сервер:

```bash
cd /data/user/0/com.agy/files/.gemini/antigravity-app/scratch/cultivation-rpg
python -m http.server 8080
```

После запуска откройте в браузере: `http://localhost:8080`

### 2. Запуск через GitHub Pages (без скачивания)

Репозиторий настроен на GitHub: `https://github.com/Valdorius/cultivation-rpg`

Чтобы игра была доступна по постоянной ссылке в интернете:
1. Перейдите в **Settings** $\rightarrow$ **Pages** в репозитории `Valdorius/cultivation-rpg`.
2. В секции **Build and deployment** выберите ветку `main` и папку `/(root)`.
3. Игра станет доступна по адресу: `https://valdorius.github.io/cultivation-rpg/`
